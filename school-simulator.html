Use a real Google account

Paste an OAuth Web application client ID from the Google Cloud console, with this page's origin () listed under its authorised JavaScript origins. The button above then becomes Google's own account chooser — tap, pick an account, done. Saving it here covers this browser only; put the same ID in GOOGLE_CLIENT_ID at the top of the file to cover everyone. Without a client ID the button makes a local Google-style profile instead.

Accounts, passwords and save files stay in this browser's localStorage — there is no server and nothing leaves your device. Passwords are salted and hashed before they are stored, but this is a toy: never reuse a password that matters.
